# Comfy Direct

通过本地 MCP 工具调用自己的 ComfyUI：上传参考图、提交 H3 视频工作流、查询任务、取回原片和 SeedVR2 高清版。

## 选择安装入口

- **通用 MCP**：使用 `generic-mcp/安装通用MCP-Windows.ps1` 或 Mac 对应脚本。不需要 Codex；需要支持本地 stdio MCP 的客户端。安装后导出 `mcp-client.json`，按客户端要求添加其中的工具配置。
- **Codex 插件**：使用仓库根目录的 `安装插件-Windows.ps1` 或 Mac 对应脚本。这一路径需要 Codex CLI。已有独立连接的迁移说明见 `Codex插件使用说明.txt`。

[下载版本包](https://github.com/khons001/comfy-direct/releases/latest)

## 使用前提

自行准备安装了匹配模型、节点和工作流的 ComfyUI 服务器。程序不提供算力，不包含模型权重，也不会自动开通或充值服务器。

本地需要 Node.js 22.18 或更高版本；安装脚本可准备便携运行时。SSH 密码在本机连接窗口输入，不放入聊天或仓库。默认本地转发端口为 18190，服务器 ComfyUI 端口为 8188。

安装后，通过连接管理脚本连接自己的服务器，保持连接窗口打开，再让 Agent 调用工具。服务器端口变化后重新配置 SSH 信息。

## 验证范围

- Windows：安装、MCP 工具发现、任务持久化、重复请求去重与无 GPU 拦截已验证。
- 核心：RTX 4090 上真实完成 H3 生成、SeedVR2 放大和两版自动取回。
- Mac：脚本语法和模拟安装流程通过，尚未真机验证。
- 通用接口不绑定模型；不同客户端的配置和媒体展示可能不同。未宣称 DeepSeek 官网聊天可以直接安装本地工具。

默认视频参数为 10 秒、0.6MP、turbo=false。实际适用参数取决于服务器显存。使用稳定 request_key 避免重复生成；恢复任务时使用原任务 ID。
