Comfy Direct · 跟着视频，五步完成部署（v0.1.3）

先准备服务器，再回到 Agent 安装 MCP。下面按教学视频的顺序操作，以算家云为例。

1. 租好服务器，设置密码
去哪里：算家云的服务器实例页面。

选择带 NVIDIA 显卡的服务器。视频演示使用 RTX 4090、24GB 显存；基础镜像选择带 Python 3.12 的 PyTorch 环境。数据盘建议留出150GB空间，确认费用后创建并开机。

打开这个实例的 WebShell，复制下面的命令，粘贴并回车：

passwd root

输入你要设置的密码，回车，再输入一次相同密码并回车。输入时看不到字符或星号是正常的。

完成标志：出现密码修改成功的提示。记好这个密码，后面连接时要用。

2. 在电脑上登录服务器
去哪里：先回到算家云实例页面，打开“SSH连接”。

复制平台给你的第一行完整 SSH 命令。每个人的命令不同，使用你自己页面上的那一条。

Windows：按 Win + R，输入 powershell 并回车。
Mac：打开“终端”。

把刚才的 SSH 命令粘贴进去并回车。第一次连接若询问是否信任服务器，核对后输入 yes；出现 password 时，输入第1步的密码并回车。

完成标志：看到 root@ 开头的命令提示符。保持这个窗口打开，下一步继续用它。

3. 安装并启动 ComfyUI
去哪里：第2步已经登录服务器的那个窗口。

先复制下面的安装命令，粘贴并回车，等待模型和环境安装完成。这里使用算家云目录；其他平台或已安装过的环境，先看下方排错说明，确认实际目录。

mkdir -p /root/sj-tmp && cd /root/sj-tmp && curl -fL --retry 3 https://github.com/khons001/comfy-direct/releases/download/v0.1.3/video-server-install.run -o video-server-install.run && echo '2641c1d35203780d97c89d8f20589961a1c91e1d84088e75acd31d7aa1e63473  video-server-install.run' | sha256sum -c - && bash video-server-install.run --root /root/sj-tmp/ComfyUI

看到 Installation checks finished，并且没有报错后，再复制下面的启动命令，在同一个窗口粘贴并回车：

cd /root/sj-tmp/ComfyUI && .venv/bin/python main.py --listen 127.0.0.1 --port 8188

完成标志：出现服务启动和 http://127.0.0.1:8188 的提示。保持这个窗口打开，然后回到 Agent。

4. 让 Agent 下载安装 MCP
去哪里：你使用的 Agent 对话框。视频用 Codex 演示，其他支持本地 MCP、能下载文件和执行本机命令的 Agent 也可以。

复制下面这段话发给它，不需要自己先下载安装包：

请从 https://github.com/khons001/comfy-direct 帮我下载、安装并配置 Comfy Direct 通用 MCP。服务器已经按教程启动，需要服务器连接信息时告诉我，完成后检查工具能否正常调用。

等待 Agent 下载和安装。它需要服务器连接信息时，继续下一步。

5. 发给 Agent 连接信息，开始生成视频
去哪里：回到算家云，打开同一个实例的“SSH连接”。

再次复制第一行完整 SSH 命令，把它发给 Agent。它会继续配置连接。

如果弹出连接窗口，在那个窗口输入第1步设置的密码并回车。密码不发到聊天里。保持连接窗口打开，让 Agent 检查连接。

完成标志：Agent 确认已经连接 ComfyUI，工具可以正常调用。现在就可以发参考图，告诉它想生成什么视频。

例如：请根据这张参考图生成一段10秒的视频，同时返回原片和高清版。

生成完成后，打开视频确认能播放，再保存到电脑。

以后每次使用
服务器开机后，让 Agent 按当前 SSH 信息重新连接，检查通过后就能继续生成，不用重复安装。视频保存好后，在平台正常关机。

排错与给 Agent 的技术说明
以下内容供遇到问题时查看，或由 Agent 读取。正常操作按上面的五步即可。

【平台、目录和端口】
上面的命令以算家云、root用户为例。其他平台按其说明设置登录密码，使用自己的SSH用户名、主机和端口。安装前确认真实数据盘挂载位置与容量；不能用mkdir代替挂载数据盘。
本教程新安装明确使用 --root /root/sj-tmp/ComfyUI，与第3步启动命令一致。此前装在 /root/sj-tmp/video-demo/ComfyUI 或其他目录的用户，应复用原环境，把启动命令和MCP配置同时改为实际目录，不重新覆盖安装。已有非本安装器创建的目录会被保护性拒绝覆盖，应先检查，不能直接删除。
SSH端口来自平台；ComfyUI服务端口默认8188；电脑本地转发端口由工具选择。这三者不能混用。MCP使用本地stdio，不需要开放公网MCP端口，ComfyUI也不需要直接暴露公网。

【服务器安装失败】
需要Linux x86_64、匹配的NVIDIA驱动/GPU和Python3.12（含venv/ensurepip）。模型约48.3GB，依赖、缓存、安装包和视频另占空间。缺少venv时，Debian/Ubuntu可安装python3.12-venv，或改用完整Python3.12镜像；不要替换系统Python。
下载或安装失败时保留错误记录，交给Agent排查后重试。Installation checks finished只表示安装检查结束，实际生成仍要验证。

【Agent 获取安装包】
用户在第4步才让Agent安装本地工具。先读取本仓库README和部署与使用.txt，检查系统、客户端配置方式和已有安装。只使用通用MCP，不使用历史专属插件。
下载地址：https://github.com/khons001/comfy-direct/releases/download/v0.1.3/comfy-direct-generic-mcp-v0.1.3.zip
SHA256：60bde2de2c172015357d5be3e6f980046c7fd2ad0e1da6c70384f52e9b4a2ec5
由Agent下载、校验、完整解压。网络失败如实报告，校验失败不执行。
用户尚未提供SSH命令时，先准备本地工具，不猜测服务器信息：Windows在解压目录运行 powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\安装通用MCP-Windows.ps1 -PrepareOnly；Mac运行 bash 安装通用MCP-Mac.sh --prepare-only。
安装器输出mcp-client.json，由Agent按当前客户端格式合并command、args、env，保留已有其他工具，按客户端要求重新加载。准备完成不等于已连接服务器。
默认安装目录：Windows为%LOCALAPPDATA%\ComfyDirect；Mac为~/Library/Application Support/ComfyDirect。不要移动安装目录后继续使用旧配置。

【第5步配置和连接】
取得用户当前完整SSH命令后，使用实际Node路径运行安装目录bin.mjs configure，传入--ssh-command、--remote-root、--remote-port及--local-port auto。Windows实际Node路径记录于runtime-location.json，Mac为runtime-node.txt；COMFY_DIRECT_CONFIG指向安装目录data/config.json，COMFY_DIRECT_DATA_DIR指向安装目录data。重复配置应保留已有任务和视频。
服务器目录取用户实际安装位置；按本教程新装的是/root/sj-tmp/ComfyUI。第3步已有ComfyUI运行，连接时复用它，不再启动第二个同端口服务。
Windows连接入口：powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\ComfyDirect\管理连接.ps1"。Mac：bash "$HOME/Library/Application Support/ComfyDirect/manage.sh" connect。安装目录自定义时使用实际路径。需要密码时打开用户可交互的本机窗口，让用户自己输入。
调用comfy_check确认connected、gpu_available、generation_ready为true，missing_nodes和unavailable_inputs为空。失败则按错误排查；模型枚举检查不等于模型内容完整或显存足够。
普通网页聊天、只有模型API或只接受远程MCP URL的客户端不能直接运行本地stdio MCP，应先说明客户端能力限制。

【生成与验证范围】
生成需要可读取的参考图路径。没有图时，可由支持图像生成的Agent先制作参考图，并让用户确认。使用稳定request_key提交一次，之后按job_id查询；断线恢复原任务，不盲目重提。
两版视频下载且能播放才算完成。内嵌播放能力取决于客户端；也可以打开返回的本地文件。生成时保持电脑联网、唤醒、服务器和连接窗口运行。
Windows隔离安装、MCP协议调用、Linux CPU依赖及服务启动已验证。Mac/ARM64真机、各客户端完整链路及全新GPU服务器实际生成未逐项验收。CPU测试不能当作GPU生成成功。
