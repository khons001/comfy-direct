Comfy Direct · 通用 MCP 部署与使用（v0.1.3）

把这份教程交给你的 Agent，并告诉它：
请按教程检查我的电脑和服务器，安装通用 MCP 并接入当前客户端。先复用已有环境，缺什么再安装。向我索取当前 SSH 命令，记录实际服务器目录和端口；密码由我在本机连接窗口输入。先检查连接、GPU、节点和模型，再提交一次测试任务，不重复生成。

适用范围
本地工具需要支持本地 stdio MCP、可访问本机文件的 Agent 客户端。让 Agent 代为安装，还需要本机命令执行能力。仅有模型 API 或普通网页聊天账号不够；只支持远程 MCP URL 的客户端不能直接填写本包配置。不同客户端共用同一套工具，模型由客户端配置。
本地安装入口支持 Windows / macOS；Windows x64 已做隔离安装测试，Mac 和 Windows ARM64 未真机验证。Linux GPU 服务器安装器使用 Python 3.12。本轮未在新租 GPU 服务器上重新生成视频。
项目：https://github.com/khons001/comfy-direct
教程：https://khons.cloud/comfy-direct.html

1. 准备服务器和连接信息
操作位置：你的 GPU 平台。

• 已有匹配的 ComfyUI 时，先检查实际目录、服务端口、GPU、节点和模型，不重新覆盖安装。
• 新建环境请选择 NVIDIA GPU、Linux x86_64、Python 3.12（含 venv/ensurepip）的镜像。演示使用 RTX 4090 24GB；不代表所有显卡都能运行相同参数。
• 模型合计约48.3GB，依赖、安装包、缓存和视频另占空间。建议150GB数据盘，并让Agent用df -h确认实际挂载位置与可用容量；mkdir不能创建或挂载数据盘。
• GPU和存储按平台收费，由你确认费用并开机。普通无GPU的网站服务器不满足视频生成要求。
• 从平台复制当前完整SSH命令，包含用户名、主机和-p后的端口。密码不发到对话中；如果平台要求设置密码，在自己的WebShell里按平台说明设置。

Windows打开PowerShell，Mac打开终端，执行自己的SSH命令。首次连接核对主机指纹；按提示在本机窗口输入密码。看到远端命令提示符后，才执行下一步服务器命令。

2. 在服务器安装环境
操作位置：上一步登录后的服务器终端。

下面命令仅以算家云的 /root/sj-tmp 数据盘为例。其他平台先让Agent确认实际数据盘目录，再同时修改cd所在目录和--root后的安装目录。不要照抄别人的绝对路径。

mkdir -p /root/sj-tmp && cd /root/sj-tmp && curl -fL --retry 3 https://github.com/khons001/comfy-direct/releases/download/v0.1.3/video-server-install.run -o video-server-install.run && echo '2641c1d35203780d97c89d8f20589961a1c91e1d84088e75acd31d7aa1e63473  video-server-install.run' | sha256sum -c - && bash video-server-install.run --root /root/sj-tmp/video-demo/ComfyUI

安装器下载锁定版本的模型并校验文件，保留非本安装器创建的已有目录。等待Installation checks finished且没有错误退出；这表示安装检查完成，不等于已经生成视频。
若提示缺少venv/ensurepip：Debian/Ubuntu可在服务器安装python3.12-venv，或使用带完整Python3.12的镜像。安装器不会替换系统Python。若下载失败，保留原目录和错误记录，修复网络后重试。
如环境不是Python3.12、Linux x86_64或没有匹配GPU/驱动，先处理环境问题，不强行继续。源码、依赖清单、模型清单都在安装器展开目录内。

3. 在自己的电脑安装通用 MCP
操作位置：你的电脑，不是GPU服务器。

下载并完整解压：
https://github.com/khons001/comfy-direct/releases/download/v0.1.3/comfy-direct-generic-mcp-v0.1.3.zip

Windows：在解压目录打开PowerShell，执行：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\安装通用MCP-Windows.ps1

此参数只作用于本次脚本进程，不修改系统执行策略。公司设备若策略禁止执行，应按设备管理要求处理。
Mac：在解压目录执行：
bash 安装通用MCP-Mac.sh

安装器会复用符合要求的Node，或从Node官方站点下载并校验便携运行时。无需安装Codex或Codex CLI。
按提示填写自己的SSH命令、服务器ComfyUI绝对目录和服务端口。算家云示例目录是/root/sj-tmp/video-demo/ComfyUI，服务端口默认8188；换平台就填自己的实际值。本地转发端口自动选择，默认18190被占用时会选其他空闲端口。
安装后读取安装器输出的mcp-client.json，将其中command、args、env按当前客户端的配置格式合并，保留其他MCP工具。它引用的是在这台电脑实际生成的路径，不要复制作者或别人的mcp-client.json。
默认安装目录：Windows为%LOCALAPPDATA%\ComfyDirect；Mac为~/Library/Application Support/ComfyDirect。不能安装后移动该目录。需要换目录时重新安装并更新客户端配置。
成功标志：重新加载客户端后可发现comfy_check等7个工具。

4. 连接服务器并检查
操作位置：你的电脑上的独立终端窗口。需要密码时由你输入。

Windows：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\ComfyDirect\管理连接.ps1"

Mac：
bash "$HOME/Library/Application Support/ComfyDirect/manage.sh" connect

若安装时指定了其他本地目录，使用实际安装目录。连接脚本会在配置的服务器目录查找main.py和.venv/bin/python，复用已有ComfyUI或启动该环境，无需再重复手动启动服务。保持连接窗口打开。
让Agent调用comfy_check，确认connected、gpu_available、generation_ready为true，且missing_nodes和unavailable_inputs为空。它检查节点与模型选项是否注册可用，不能替代实际生成测试，也不能保证显存一定足够。
三个端口不要混用：SSH端口来自平台；ComfyUI服务端口通常8188；电脑本地转发端口由工具选择。MCP本身使用stdio，不需要另开公网MCP端口，也不要把ComfyUI直接开放到公网。
若本地端口后来被其他程序占用，先检查是否已有连接；确认没有后，让Agent重新配置--local-port auto，再连接。若平台SSH端口变化，更新SSH命令后重连，不重装服务器。
如果已有直接可访问的ComfyUI接口，可用--endpoint配置直接连接；该模式不运行SSH连接脚本。不要把端口18190或8188当成远程MCP URL。

5. 生成并保存视频
操作位置：Agent对话。

上传参考图，让Agent确认图片已有可读的本地绝对路径，再发送：
请根据这张参考图和我的描述生成一段10秒视频，同时返回H3原片和SeedVR2高清版。

第一次可以先做一条较短的视频确认整条链路。Agent使用稳定request_key提交一次，拿到job_id后持续查询该任务；断线后恢复原任务，不盲目重提。显存不足时再降低参数或先关闭高清放大排查。
保持电脑唤醒、联网，GPU服务器和连接窗口运行。完成标志是两版视频已下载到电脑并能播放；只显示“任务已提交”不算完成。客户端可能展示文件路径或链接，内嵌播放能力取决于客户端。

以后每次使用
• 在平台以GPU模式开机，取得最新SSH信息；变化时更新配置。
• 打开本地连接入口，让Agent运行comfy_check，再上传图片和描述。
• 两版视频保存并确认可播放后，在平台正常关机；保留实例和数据盘。

给Agent的配置参数参考
Windows安装脚本支持-SshCommand、-RemoteRoot、-RemotePort、-LocalPort auto、-Destination；-PrepareOnly只准备工具，不伪造连接成功。
Mac安装脚本支持--ssh-command、--remote-root、--remote-port、--local-port auto；COMFY_DIRECT_INSTALL_DIR指定本地目录；--prepare-only只准备工具。
已安装后：读取runtime-location.json（Windows）或runtime-node.txt（Mac）得到实际Node路径，使用它运行安装目录中的bin.mjs configure，传入上述对应的长参数。使用同一安装目录的data/config.json和data目录，不改其他客户端工具。
更新连接必须保留已有任务和下载视频。不要把SSH密码、个人地址或本机路径写进分发包。
